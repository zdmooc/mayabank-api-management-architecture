# ADR-006 — API + Events

## Statut
Proposé

## Contexte
Le paiement combine commandes synchrones et propagation asynchrone.

## Décision
REST pour initier/consulter ; Kafka pour diffuser les événements de cycle de vie.

## Conséquences
Deux contrats à gouverner : OpenAPI et AsyncAPI.

## Validation
À confirmer pendant les labs et selon le contexte client réel.
