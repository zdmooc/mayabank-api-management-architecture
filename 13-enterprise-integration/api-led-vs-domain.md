# API-led connectivity vs Domain APIs

Ne pas confondre une taxonomie produit avec une architecture métier universelle.

Une décomposition possible :
- Experience APIs ;
- Process APIs ;
- System APIs.

Une autre :
- Domain APIs alignées DDD ;
- Capability APIs ;
- Product APIs.

L'architecte choisit une convention cohérente avec l'organisation, évite les couches sans valeur et documente les dépendances.
