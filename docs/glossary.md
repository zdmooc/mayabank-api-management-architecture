# Glossaire

- **API Gateway** : runtime de contrôle du trafic API.
- **API Management** : gestion du cycle complet des APIs.
- **API Product** : paquet d'APIs destiné à une audience avec conditions/SLO.
- **OAuth 2.0** : protocole d'autorisation déléguée.
- **OIDC** : couche d'identité sur OAuth.
- **PKCE** : protection du code d'autorisation.
- **mTLS** : authentification TLS mutuelle.
- **DPoP** : mécanisme de preuve de possession pour lier des tokens à une clé.
- **FAPI** : profils haute sécurité basés sur OAuth/OIDC.
- **OpenAPI** : contrat machine-readable pour APIs HTTP.
- **AsyncAPI** : contrat machine-readable pour interfaces événementielles.
- **SLO** : objectif de niveau de service.
- **SLI** : indicateur mesuré.
