# Framework de comparaison

Noter chaque plateforme sur :

1. sécurité OAuth/OIDC/mTLS/FAPI capabilities ;
2. hybrid/on-prem/cloud ;
3. OpenShift support ;
4. performance/latency ;
5. HA/DR ;
6. multi-tenancy ;
7. developer portal ;
8. analytics ;
9. policy extensibility ;
10. GitOps/CI-CD ;
11. observability/OpenTelemetry ;
12. cost/licensing ;
13. operations skills ;
14. migration effort ;
15. vendor lock-in ;
16. support/SLA ;
17. ecosystem/connectors.

Produire un score + ADR, pas seulement un tableau.
