# Dépréciation et retrait

Avant retrait :

1. identifier les consommateurs ;
2. publier la date de dépréciation ;
3. fournir la version cible ;
4. mesurer le trafic de l'ancienne version ;
5. accompagner les consommateurs critiques ;
6. bloquer les nouveaux abonnements ;
7. retirer seulement quand les critères sont atteints.
