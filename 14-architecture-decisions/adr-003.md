# ADR-003 — OAuth/OIDC

## Statut
Accepté pour le périmètre lab

## Contexte
Les APIs protégées ont besoin d'une architecture d'identité standardisée.

## Décision
Utiliser OAuth 2.0/OIDC selon le type de client, avec RFC 9700 comme baseline sécurité.

## Conséquences
Nécessite une gouvernance des clients, scopes, audiences et clés.

## Validation
Validé partiellement le 2026-10-02 par la chaîne CI `runtime/e2e/` (Keycloak `client_credentials`, contrôles issuer/audience/scope, rejets 401/403) et par le profil CRC partagé. Restent à valider : Authorization Code + PKCE, mTLS/sender-constrained tokens, rotation de clés.
