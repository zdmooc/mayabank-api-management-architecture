# LAB — FAPI architecture review

**Statut : À EXÉCUTER**

## Objectif
Comparer l'architecture OAuth du lab aux exigences FAPI 2.0 sans prétendre à une certification.

## Prérequis
Documentation OpenID + checklist.

## Étapes
1. Noter toutes les versions réellement utilisées.
2. Exécuter le scénario minimal.
3. Conserver commandes et configuration.
4. Vérifier le comportement nominal.
5. Provoquer au moins une erreur contrôlée.
6. Mesurer/observer le résultat.
7. Documenter les écarts avec l'architecture cible.

## Critères de validation
- résultat reproductible ;
- aucune donnée/secrète réelle dans Git ;
- preuves conservées ;
- conclusion d'architecture ;
- ADR mis à jour si nécessaire.

## Résultats
À renseigner lors de l'exécution.
