# 06 — Plateformes API Management

Le dépôt reste vendor-neutral.

| Produit | Forces typiques à évaluer |
|---|---|
| Apigee | API management entreprise, analytics, Google Cloud ecosystem |
| Kong | cloud-native, Kubernetes/OpenShift, gateway/plugin model |
| MuleSoft Anypoint | API management + intégration/iPaaS/API-led |
| Axway Amplify | API management entreprise, intégration, environnements historiques/hybrides |

Ne pas choisir sur une matrice marketing. Faire un benchmark pondéré par exigences.
