# Certifications — stratégie

Ne pas collectionner les badges. Chercher d'abord la compétence démontrable.

## Ordre recommandé

1. OpenAPI / API design : maîtrise pratique avant certification.
2. OAuth/OIDC/FAPI : compréhension protocolaire et sécurité.
3. Une plateforme principale :
   - Kong si orientation cloud-native/OpenShift ;
   - Apigee si forte cible Google Cloud / grande entreprise ;
   - MuleSoft si intégration/iPaaS + API-led connectivity ;
   - Axway si environnement déjà standardisé Axway.
4. Certifications constructeur seulement lorsque le marché ciblé les valorise.

## Critère

Une certification doit répondre à une question : « augmente-t-elle réellement mes chances d'obtenir une mission ? »
