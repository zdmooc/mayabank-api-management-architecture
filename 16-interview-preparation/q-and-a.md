# Réponses courtes d'entretien

## API Gateway vs API Management
Le gateway est le runtime de contrôle du trafic. API Management couvre aussi design, publication, catalog, products, portal, policies, analytics, lifecycle et governance.

## OAuth vs OIDC
OAuth délègue l'autorisation d'accès aux ressources. OIDC ajoute une couche d'identité/authentification au-dessus d'OAuth.

## Quota vs rate limit
Le rate limit borne un débit sur une petite fenêtre ; le quota borne une consommation sur une période plus longue ou un plan.

## OpenAPI vs AsyncAPI
OpenAPI décrit principalement des APIs HTTP ; AsyncAPI décrit des interfaces message-driven/event-driven.

## Double paiement
Idempotency key, stockage du résultat associé, règles backend, timeouts/retries contrôlés et identifiant métier.
