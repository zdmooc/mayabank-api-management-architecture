# Architecture Review Checklist

- [ ] business capability et consumers identifiés
- [ ] owner nommé
- [ ] OpenAPI/AsyncAPI disponible
- [ ] données classifiées
- [ ] authN/authZ définies
- [ ] scopes/audiences définis
- [ ] TLS/mTLS justifiés
- [ ] idempotence définie si commande
- [ ] rate limit/quota définis
- [ ] timeout/retry/circuit breaker définis
- [ ] erreurs standardisées
- [ ] SLO et observabilité définis
- [ ] versioning/deprecation définis
- [ ] HA/DR définis
- [ ] coût et licensing considérés
