# ADR-002 — Gateway vs Service Mesh

## Statut
Proposé

## Contexte
Les responsabilités north-south et east-west doivent être séparées.

## Décision
Le gateway gère l'exposition API ; le mesh gère principalement le trafic service-to-service.

## Conséquences
Évite le chevauchement de policies.

## Validation
À confirmer pendant les labs et selon le contexte client réel.
