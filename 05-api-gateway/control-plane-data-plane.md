# Control Plane / Data Plane

## Control Plane

- configuration ;
- catalog ;
- policy definitions ;
- keys/apps/products ;
- analytics configuration ;
- governance.

## Data Plane

- exécute le trafic réel ;
- doit rester performant et disponible ;
- ne doit pas dépendre d'un control plane distant pour chaque requête.

Sujet critique pour architecture hybride/multi-site.
