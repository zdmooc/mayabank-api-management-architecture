# Exigences POC

## Fonctionnelles

- créer un paiement ;
- consulter un paiement ;
- diffuser changement de statut.

## Non fonctionnelles

- OAuth/OIDC ;
- TLS ;
- idempotence ;
- quota/rate limit ;
- logs sans données sensibles ;
- correlation ID ;
- métriques ;
- timeout ;
- 2 replicas pour service lorsque possible ;
- manifests versionnés ;
- contract-first.
